KHÁM PHÁ KHOA HỌC 5

Kiểm tra bộ web trước khi tải lên GitHub

Chọn thư mục SKKN-KH trên máy, sau khi đã chép đầy đủ bộ web. Công cụ sẽ kiểm tra sự có mặt, kích thước và nội dung của 706 file cần thiết.

Việc kiểm tra chạy ngay trên máy và không gửi file đi. Các file khác sẵn có trong repo được bỏ qua. Đây là kiểm tra bộ file trên máy, không phải kiểm tra website đã xuất bản.

Thư mục được chọn cần chứa ngay index.html, assets và icons. Nếu chưa đủ, chép lại toàn bộ nội dung từ bộ ZIP đã giải nén rồi kiểm tra lại.
